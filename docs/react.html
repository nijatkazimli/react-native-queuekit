React hooks

Live job status for your UI. The hooks are a thin layer over queue.subscribe() using useSyncExternalStore, so they are tear-free and re-render only when jobs change.

Import from the separate entry point, so the core stays free of React: import { ... } from "@nijatk/react-native-queuekit/react". React 18 or newer is required.

QueueProvider

The provider only makes the queue available to hooks. It does not start or stop it: the queue starts when created (unless autoStart: false).

Performance notes

  • Components re-render on any job change. Scope hooks narrowly: a list screen uses useJobs({ type }), a badge uses useQueueStats().
  • Progress updates write to storage and notify subscribers on every progress() call. Throttle in the handler if your source reports hundreds of events per second: report every 1% or every 250 ms.
  • useJob(id) scans the job list. It is perfect for individual rows, but for thousands of jobs prefer one useJobs at the list level and pass jobs down.
  • Use React.memo for rows keyed by job.id. A job object is replaced when it changes, so unchanged rows keep their reference.
