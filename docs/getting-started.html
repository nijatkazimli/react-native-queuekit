Getting started

From zero to a job that survives airplane mode, in about ten minutes. This page covers installation, the native pieces, creating the queue, defining a job and showing its status.

Requirements

  • React Native 0.76 or newer (required by react-native-mmkv 4).
  • Expo users need a development build. react-native-mmkv is a native module, so Expo Go cannot run it.
  • React 18 or newer if you use the hooks from @nijatk/react-native-queuekit/react.
  • TypeScript is optional but recommended. Types ship with the package.

Install

Why NetInfo is recommended

Without a network monitor the queue assumes the device is always online. It still works, but offline attempts fail and use up retries, and nothing reacts to reconnecting. See Network monitors.

Define your first job

queue.define(type, handler) registers the handler and returns a function that enqueues the job. The payload type is taken from the handler's first parameter.

Enqueue it

The call is synchronous and returns the stored Job. If the device is online the job starts right away. If not, it waits.

Try it

  1. Turn on airplane mode.
  2. Enqueue a job. It appears as pending and nothing is sent.
  3. Force-quit the app and reopen it. The job is still there.
  4. Turn airplane mode off. The job runs and disappears.

If something does not run, see the checklist in FAQ.

Optional: decorators setup

Class-method decorators (@queue.handler) use the standard TC39 syntax. Skip this section if you use queue.define().

In tsconfig.json leave experimentalDecorators off. Do not enable it: those are the older, incompatible decorators. Expo projects use babel-preset-expo instead of the preset above; add the same plugin to the plugins array.

Not tested on a device yet

Metro and Hermes handling of decorators depends on your Babel setup. If you hit issues, queue.define() needs no configuration and does the same job.

Suggested project layout

Keeping one job per feature file means no central list of handlers to maintain, and the queue module never imports feature code.
